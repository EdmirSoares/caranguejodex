# ADR 0008 — Certificado com link público verificável

**Status:** aceita · code jam DevFest Aracaju

## Contexto

Certificados genéricos de presença em PDF não têm valor para quem recebe.

## Decisão

O certificado lista as conquistas e tem um link público com código verificável, pronto para o LinkedIn.

## Consequências

Ele vira prova compartilhável. Cada certificado precisa de uma página pública (mock no protótipo).
