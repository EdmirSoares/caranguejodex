# ADR 0004 — XP por nível de validação

**Status:** aceita · code jam DevFest Aracaju

## Contexto

Pontuar pelo tipo de missão rebaixaria o estande, e há patrocinadores que só têm estande.

## Decisão

O XP depende de como a missão é validada: bronze 10 (scan simples), prata 30 (outra pessoa confirma), ouro 50 (desafio concluído).

## Consequências

Um patrocinador só de estande consegue oferecer missão ouro. As regras ficam um pouco mais difíceis de explicar.
