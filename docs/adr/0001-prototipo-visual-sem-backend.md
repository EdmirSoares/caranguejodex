# ADR 0001 — Protótipo visual navegável, sem backend

**Status:** aceita · code jam DevFest Aracaju

## Contexto

A code jam tem cerca de 1 hora. Não há tempo para projeto, backend e deploy, e o que os jurados avaliam é a experiência.

## Decisão

O protótipo é um conjunto de telas navegáveis feitas no Claude Design, com estados simulados (scan, consentimento, escolha de skin).

## Consequências

Nada é persistido e não há autenticação. Os fluxos são telas ligadas entre si; a lógica real fica para depois da code jam.
