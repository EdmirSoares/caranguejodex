# ADR 0009 — O Crabuntu é a insígnia, com uma skin por patrocinador

**Status:** aceita · code jam DevFest Aracaju

## Contexto

Insígnias genéricas não dão motivo para circular pelo evento. A comunidade já tem um mascote querido, o Crabuntu.

## Decisão

Cada patrocinador define uma skin do Crabuntu (cor e acessório da marca). Capturar todas completa a Caranguejodex e libera o caranguejo Lendário.

## Consequências

Colecionar leva o participante a todos os estandes. Cada skin precisa de uma ilustração própria na versão final; o protótipo só recolore o mascote.
