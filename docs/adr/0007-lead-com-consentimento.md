# ADR 0007 — Lead só com consentimento granular

**Status:** aceita · code jam DevFest Aracaju

## Contexto

Participantes evitam apps que os transformam em lista de contatos, e a LGPD exige base legal para compartilhar dados.

## Decisão

Ao capturar um caranguejo, o participante escolhe o que compartilha com o patrocinador: LinkedIn, e-mail, aceita contato sobre vagas. As opções começam desmarcadas.

## Consequências

Patrocinadores recebem menos leads, porém mais qualificados e com consentimento registrado.
