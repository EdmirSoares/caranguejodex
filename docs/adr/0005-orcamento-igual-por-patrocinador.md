# ADR 0005 — Orçamento igual de 150 pts por patrocinador

**Status:** aceita · code jam DevFest Aracaju

## Contexto

Sem limite, patrocinadores poderiam inflar o jogo com missões de muitos pontos.

## Decisão

Cada patrocinador recebe o mesmo teto de 150 pontos para distribuir entre suas missões.

## Consequências

O peso de cada patrocinador no jogo fica justo. Patrocinador maior não compra mais visibilidade dentro do jogo.
