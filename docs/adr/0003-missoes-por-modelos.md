# ADR 0003 — Missões só a partir de 5 modelos

**Status:** aceita · code jam DevFest Aracaju

## Contexto

Com liberdade total, o patrocinador tende a criar "escaneie o QR do meu estande", o que transforma o jogo em coleta passiva de leads.

## Decisão

O patrocinador configura missões a partir de cinco modelos: Conexão, Conhecimento, Presença ativa, Desafio de estande e Ponto de encontro.

## Consequências

Toda missão gera interação de verdade. Em troca, o patrocinador tem menos liberdade criativa.
