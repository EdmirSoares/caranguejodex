# ADR 0002 — Herói único: o participante

**Status:** aceita · code jam DevFest Aracaju

## Contexto

O app tem três públicos: participante, patrocinador e organização. Tratar os três no protótipo dilui a demo.

## Decisão

O participante é o herói. Patrocinador e organização aparecem só no que alimenta a experiência dele.

## Consequências

O painel do patrocinador é uma única tela mock. Não há painel da organização.
